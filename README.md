​6. THE OSI MODEL (LAYERS, EXAMPLES, & ATTACKS)
​Layer 7: Application
​Meaning: Interface between the user and the network.
​Telegram Example: The Telegram app screen where you type your message.
​Attack: Phishing, Malware, Application-level DDoS.
​Layer 6: Presentation
​Meaning: Data formatting, encryption, and compression.
​Telegram Example: Telegram’s MTProto encryption turning your "Hello" into unreadable code.
​Attack: Malicious file formatting, Data exfiltration.
​Layer 5: Session
​Meaning: Establishes and maintains the connection "dialogue."
​Telegram Example: The system that keeps you logged in without asking for your password every time you open the app.
​Attack: Session Hijacking (stealing a login cookie/token).
​Layer 4: Transport
​Meaning: Reliable delivery of data packets (TCP/UDP).
​Telegram Example: Ensuring your long message is broken into small pieces and put back together correctly on the server.
​Attack: SYN Flood (DDoS attack on the connection process).
​Layer 3: Network
​Meaning: Logical addressing (IP) and routing.
​Telegram Example: Finding the fastest path for your message to reach Telegram's cloud server.
​Attack: IP Spoofing, ICMP (Ping) Flood.
​Layer 2: Data Link
​Meaning: Physical addressing (MAC) and switching.
​Telegram Example: Data moving from your phone to your local Wi-Fi router.
​Attack: ARP Spoofing (Man-in-the-middle attack).
​Layer 1: Physical
​Meaning: Physical transmission media (cables, radio waves, bits).
​Telegram Example: The actual Wi-Fi or 4G/5G radio signals carrying the bits.
​Attack: Jamming (blocking Wi-Fi signals), Wiretapping.
