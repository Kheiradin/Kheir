NETWORK AND CYBERSECURITY FUNDAMENTALS
​1. NETWORK BASICS
​Definition: A network is a system of interconnected devices (computers, servers, IoT) that exchange data and share resources using a common set of rules called protocols.
​Meaning: In a modern context, a network is the "digital plumbing" that allows information to move from Point A to Point B.
​Network Types:
​PAN (Personal Area Network): Connection for a single person (e.g., Bluetooth headphones to a phone).
​LAN (Local Area Network): Small area like a home, office, or building.
​MAN (Metropolitan Area Network): Covers a city or a large campus.
​WAN (Wide Area Network): Covers large distances, like countries. The Internet is the world's largest WAN.
​2. IP ADDRESSING (INTERNET PROTOCOL)
​An IP address is a logical address used to identify a device on a network.
​IP Components:
​Network Part: Identifies the specific network the device belongs to.
​Host Part: Identifies the specific device (host) on that network.
​IPv4 Classes:
​Class A: 1.0.0.0 to 126.255.255.255 (Large networks)
​Class B: 128.0.0.0 to 191.255.255.255 (Medium networks)
​Class C: 192.0.0.0 to 223.255.255.255 (Small networks - most common)
​Class D: 224.0.0.0 to 239.255.255.255 (Multicasting)
​Class E: 240.0.0.0 to 255.255.255.255 (Experimental)
​IPv4 vs IPv6:
​IPv4: 32-bit address, numeric (e.g., 192.168.1.1). Limited to ~4.3 billion addresses.
​IPv6: 128-bit address, alphanumeric (e.g., 2001:0db8:85a3:0000:0000:8a2e:0370:7334). Created to provide nearly infinite addresses.
​3. TRANSPORT PROTOCOLS (TCP & UDP)
​TCP (Transmission Control Protocol): Connection-oriented. It ensures all data arrives correctly and in order via a "handshake." It is reliable but slower.
​UDP (User Datagram Protocol): Connectionless. It sends data without checking if it was received. It is very fast but unreliable (best for gaming/video calls).
​4. MAC ADDRESS
​Definition: Media Access Control address.
​Meaning: A unique hardware identification number burned into every Network Interface Card (NIC).
​Format: 48-bit hexadecimal (e.g., 00:1A:2B:3C:4D:5E).
​Difference: Unlike IP addresses (which change), the MAC address is permanent to the physical hardware.
